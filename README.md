# Personal Web Project

This repository contains the source code for a personal website and portfolio. Below is an overview of the main pages included the secret pages.

## Project Structure

The pages included in this project are:

* **`index.html`**: The main home page of the website.

* **`aboutme.html`**: A section dedicated to personal and biographical information.

* **`contacts.html`**: The contact page to get in touch.

* **`projects.html`**: An overview of completed projects.

* **`gdev.html`**: A page that redirect to Google Developer Account.

* **`leetcode.html`**: A page that redirect to Google Account.

* **`treemap.html`**: A map of available trees.

* **`worldvertiser.html`**: A page about my old project based on workflow.

* **`404.html`**: A custom error page for broken or missing links.

* **`images/`**: A directory containing visual assets and media for the site.
