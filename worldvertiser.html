Worldvertise constitues an automated utility designed for the generation and email delivery of a daily information summary. This tool integrates real-time data from three distinct external sources: financial markets, current weather conditions, and major news headlines, producing a highly structured HTML report suitable for routine information monitoring.

The process begins in the configuration section (section 1), where all essential credentials and parameters are centralised to facilitate maintenance. Email credentials are defined (sender's address, recipient, and the specific Google app password necessary for secure access to the Gmail SMTP server), along with key identifiers for external services, such as the API keys for NewsAPI and OpenWeatherMap, and the target city for meteorological information. A crucial element of this section is the index dictionary, which associates common market index names with their respective tickers recognised by the yfinance library.

The data retrieval functions section (section 2) is responsible for obtaining and pre-processing the raw data. The get_news() function establishes a connection with NewsAPI to acquire the five most recent news articles in Italian, extracting the title, source, and clickable URL. Concurrently, the get_weather(city) function queries OpenWeatherMap to retrieve the current temperature and a textual description of the conditions. The most complex component, get_stock_market(indici_map), utilises the yfinance library to download the latest opening and closing prices for all defined indices.

Subsequently, it calculates the daily percentage change. It applies inline CSS styles to the resulting HTML code, conditionally formatting the price and variance in green for increases and red for decreases, ensuring immediate visual interpretation within the email message.

The final stage is managed by the email sending function (send_daily_summary) (section 3), which orchestrates the assembly and transmission of the final report. This function first aggregates all the data produced by the retrieval functions and constructs the final email body as a comprehensive, well-structured HTML document.

News items are incorporated as clickable hyperlinks, while the market and weather reports are inserted using the styled HTML elements generated previously. Finally, it employs the standard Python library smtplib to establish a secure ssl connection with the Gmail SMTP server and, following authentication via the app password, dispatches the compiled email message to the designated recipient, ensuring reliable, automated delivery of the daily briefing.
